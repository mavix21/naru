## Commands

- `pnpm dev` from the repository root starts the contract watcher and Next.js.
- `pnpm --dir app dev` starts only Next.js (no local network needed).
- `pnpm --dir app build` runs the production build and typecheck.
- `pnpm --dir app start` serves the production build.
- `pnpm run lint`, `pnpm run format:check` run Oxlint and Oxfmt.

## Architecture

The App Router lives in `src/app`. Route views and the layout are server components;
the wallet, notification and contract form controls are client components. The
wallet SDK is imported dynamically in the browser so prerendering does not load
browser-only dependencies. Contract clients in `app-lib/clients` are generated by
`stellar scaffold watch --build-clients`. Network settings exposed to the client
use the `NEXT_PUBLIC_STELLAR_*` variables in `.env.example`.

The shared UI uses Cache Components and Partial Prefetching. Local Friendbot
requests at `/friendbot` are rewritten to the local Stellar network.
